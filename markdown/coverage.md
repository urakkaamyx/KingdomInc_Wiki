## How to read this wiki

Mechanics guides explain the gameplay rules. Individual reference pages list definition values and relationships. Source audit pages inventory every file and link back to its documented topics. Implementation details retain complex expressions for traceability. Base values should not be treated as final throughput or live combat performance.

## Limits and unresolved work

Static inspection does not validate Unity prefab settings, runtime mod patches or actual gameplay results.

Some definition fields are callbacks or dynamic expressions. They remain labeled in implementation details rather than being evaluated or assigned invented values.

Developer-only or hidden definitions are included and labeled where established by code. Presence in the assembly does not prove normal-game availability.

Icons use the existing local sprite export; mechanics and English text use the freshly inspected build.

Every source file is inventoried. Files without explanatory citations are listed explicitly in the audit.

## Files without explanatory citations

These files are inventoried, but no explanatory article currently cites them. UI and support files often appear here; inspect their source reference before assuming coverage is complete.
