# Terminus Gorge

Stage 3 of Orcish Horde.

## Description

For centuries, this dry gorge formed the eastern border of Yensburg's territory, a natural barrier separating it from the Hinterlands beyond. These days, the fortress at Terminus is deserted, save for a mad hermit that has managed to keep the orcs at bay.

## Reward Description

Retake the gorge to unlock the Summoning Circle tech!

## Reward Complete
